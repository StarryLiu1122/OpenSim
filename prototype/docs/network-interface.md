# V5 网络客户端界面与操作

更新日期：2026-09-20。适用于 0.5.1 网络客户端；世界格式、网络协议和数据库结构保持不变。

## 工作区

顶部显示连接与漫游状态，右侧提供五个工具页，底部持续显示准备、提交、成功或失败状态。工具与指南可以分别收起。网络客户端缩放窗口时保留文字和控件的可读尺寸；桌面验收覆盖 1440×900 和 1100×700。手机与触摸交互不在本次验证范围。

| 区域 | 操作 |
| --- | --- |
| 场景 | 按名称搜索对象、选择对象、双击定位、新建方块、选择 GLB |
| 属性 | 修改名称和世界坐标、保存或撤回未提交的草稿、定位、切换门灯、确认删除 |
| 连接 | 服务地址、隐藏显示的令牌、连接、断开、重试失败的资产 |
| 高级 | 完整命令及 JSON 参数、持久化回执查询、观察记录导出、诊断统计 |
| 资产 | 已有模型复用、GLB 来源和许可表单、提交模型、按原始尺寸放入场景 |

对象和角色计数对应客户端当前收到的空间范围，不代表整个区域的总量。

## 漫游与场景编辑

1. 等待顶部出现“已连接 · 可探索”。连接或碰撞资源尚未准备完成时，漫游按钮禁用。
2. 点击“进入漫游”或按 Tab。WASD 移动、鼠标转向、空格跳跃、Esc 返回编辑。漫游自动隐藏右侧工具与指南，显示中心标记。
3. 输入文本时 Tab 用于控件间导航；确认框与文件对话框不会触发漫游快捷键。窗口失去焦点或浏览器释放指针锁时退出漫游并停止移动输入。
4. 编辑状态可以直接点选三维对象，也可从列表选择；右侧自动进入属性页。F 或“定位到对象”对准选中物体；右键拖动环视，滚轮调整观察距离。右键单击地点打开“前往／建造／放置当前模型／聚焦”菜单；漫游时滚轮改变视角。Ctrl+0 拉近、Ctrl+8 拉远、Ctrl+9 重置；Alt+左键对焦。
5. 修改后点击“保存对象修改”。仅发送实际修改的字段，名称修改不会把未编辑的位置重新取整。组合成员显示世界坐标，领域层负责转换回组内坐标。
6. 同步更新不会覆盖本地草稿；存在草稿时，需要先保存或撤回，再选择其他对象。服务端拒绝保存时保留草稿。只有成功回执才能清除待保存状态。
7. 删除独立对象需要确认，取消不改变世界。组合成员不能单独删除，需先解除组合或通过高级命令删除整个组合。网络模式目前没有共享撤销历史。

只读主体可查看、定位和漫游；属性编辑和创建等操作禁用。其他主体拥有的对象同样禁用编辑，服务端仍执行最终授权校验。

## GLB 的完整操作流程

1. 在场景页点击“导入 GLB 模型”，或在资产页选择新文件。
2. 资产页显示文件名；填写资产名称、实际授权许可、来源与署名。
3. 点击“提交模型资产”。本地进行格式检查，服务端继续执行既有验证与持久化流程；收到成功回执后，模型进入可选列表。
4. 选择模型，点击“将模型放到角色前方”。系统按原始尺寸和地面高度生成对象；保存成功、必要碰撞资源就绪后，可继续在属性页调整位置。放置不进行复杂的障碍物避让，需要用户检查与调整。

列表包含当前空间范围内对象引用的模型，以及本次会话成功上传的模型。服务端空间投影不发送未被当前对象引用的网格资产，因此客户端只在内存保留本次上传的已确认资产名称、ID 和尺寸。该元数据不作为世界状态；放置仍经过服务端授权。断开或切换主体时清除，跨会话完整资产库管理留待后续实现。新模型提交后应先放入场景，便于再次连接时选用。

桌面端另可直接选择同目录的 OBJ/MTL/PNG/JPEG；Web 端仍只选择 GLB。区域所有者可以在场景页把 256 米区域扩至 512 米，扩区不会补充城市数据。格式、大小及数量上限见[组合与资产规范](groups-and-assets.md)和[清晰建筑资源、导入与漫游](quality-import-and-navigation.md)。组合整体编辑、地形、环境等操作仍保留在高级命令页。

## 启动与升级

继续使用 [网络运行指南](network-quickstart.md) 中的 `Start-Network.ps1` 和 `Start-NetworkClient.ps1`。已经打开的桌面窗口不会自动重载脚本，关闭客户端后重新打开即可。服务协议未改变，不需要迁移用户存档。

Web 客户端与桌面共用 `network/client.gd` 和 `network/workspace_ui.gd`；浏览器使用的发布文件必须重新导出。完成导出后，把实例 `web_root` 指向新导出的 `web` 目录，再重启该实例并刷新页面。旧离线安装包中的客户端不会自动更新。

## 实现与验证入口

- `network/workspace_ui.gd`：主题、布局、工具页、按钮状态、确认对话框和用户提示。
- `network/client.gd`：选择与观察相机、漫游输入、编辑草稿、资产表单与既有网络命令之间的衔接。
- `tests/network_ui_test.gd`：使用真实 Godot 控件输入、独立权威区域及真实数据库，生成断言报告和截图。
- `tools/Test-NetworkUI.ps1`：创建全新测试实例，执行验收并关闭测试服务；已加入 `Test-V5.ps1`。

在 PowerShell 7 中复现，目录必须不存在，端口不得与其他实例重复：

```powershell
.\prototype\tools\Test-NetworkUI.ps1 `
  -Godot 'D:\Godot\Godot_v4.5.1-stable_win64_console.exe' `
  -Store 'D:\RegionStore\RegionStore.exe' `
  -HostExecutable 'D:\RegionHost\RegionHost.exe' `
  -Directory 'D:\Tests\V5 UI fresh acceptance' `
  -Port 19920
```

测试报告中“rendered”项只证明截图生成；布局和可读性还需检查实际截图。版本验收结果与证据见 [验证记录](verification.md)。
