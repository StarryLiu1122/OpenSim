# 共享世界客户端：探索、建造与我的素材

更新日期：2026-09-26。桌面端与 Web 端共用网络客户端代码；Web 发布包需要重新导出才能获得新界面。此客户端连接单区域权威服务，物体修改以服务端持久回执为准。

## 进入世界

使用[网络运行指南](network-quickstart.md)启动实例和客户端。桌面一键入口会自动填入本机地址与会话令牌；手动连接时在「连接」页输入实例的地址和属于自己的令牌。顶部出现「已连接 · 可探索」表示场景和必要碰撞资源已经准备好。第一次连接、重连或资源下载时，漫游和建造会暂时禁用。

顶部快捷入口是「漫游」「建造」「我的素材」。右侧工作台还有「探索」「连接」「高级」「推演审阅」等页面。高级页保留诊断与完整命令；日常查看、放置、编辑、地形和环境操作不需要填写 JSON。窄窗口可以收起工作台或指南；当前版本仍以桌面鼠标和键盘为主，触摸操作尚未验收。

## 探索与移动

| 操作 | 控制 |
| --- | --- |
| 进入漫游 / 返回编辑 | Tab；漫游时 Esc 返回编辑 |
| 行走与快跑 | WASD；按住 Shift 快跑 |
| 跳跃、飞行 | 空格跳跃；F 切换飞行，飞行时空格上升、Ctrl 下降 |
| 使用物体 | 对准 3.5 米内属于自己的门或灯，出现提示后按 E |
| 编辑镜头 | 右键拖动环视、中键拖动平移、滚轮缩放、Home 重置；Alt+左键对焦 |
| 选中与定位 | 单击物体选中、双击物体或按 F 定位；Ctrl+单击可多选自己的未组合物体 |
| 前往地面 | 双击地面，或右键单击地面选「前往此处」；WASD 可随时接管 |

「前往此处」目前沿直线移动。建筑或地形挡路时会停止并提示手动绕行；道路寻路、小地图和地点导航列入[体验路线](../../docs/plans/product-experience-roadmap.md)。鼠标失焦或浏览器释放指针锁时会停止漫游输入。

## 建造与编辑

1. 在「建造」页选择「预览方块位置」，或在「我的素材」选模型后选择预览。移动鼠标查看半透明轮廓，**左键确认**；按 **R** 旋转 15°，按 **Esc** 或右键取消。红色轮廓表示位置不符合当前区域的尺寸或边界规则。快速放置按钮仍可在角色前方直接创建。
2. 选中自己的独立物体后，可用「在场景中移动」或 **G** 开始移动预览；单击后等待保存回执。名称和精确坐标通过字段编辑并点击「保存名称和位置」。也可逐次旋转、缩放；这些操作均由服务器校验和提交。
3. 按住 Ctrl 在场景中选择至少两个自己的、尚未组合的物体，再点「组合选中对象」。选中组合成员可以解除组合。组合成员的单独变换仍受现有语义限制。
4. 「建造」页的地形笔刷提供模式、X/Y 中心、半径、强度和目标高程。可从视角中心读取地面坐标后应用一次笔刷。环境控件可直接设置日照、水面、雾和测量网格。地形与环境仅允许区域所有者修改。

提交未完成时相关控件禁用；被拒绝的名称和位置草稿仍留在界面，便于修改或撤回。删除需要确认。联网共享撤销尚未实现，操作前请确认目标和权限。

## 导入与个人素材

桌面可选择 GLB、同目录依赖齐全的 glTF 或 OBJ/MTL/PNG/JPEG；Web 选择 GLB。填写真实授权许可和来源后提交。成功回执到达后，模型会自动加入当前账户的个人素材库；「我的素材」可刷新、搜索、查看许可，并在退出重进后重新放置。已有模型也可手动存入个人素材。同一模型可以被多个场景物体复用。

单件仍限 2 MiB、20,000 三角形、每轴 0.2–32 米、贴图不超过 1024×1024；世界最多 **96 个导入网格**。JSON 世界存档版本 2 将模型字节存于与存档同名的 `.assets` 目录，移动或备份时须带上该目录。RegionStore 数据库使用自己的 `objects/` 内容目录和导出包；单个实例最多保留 2,048 个素材库条目，以及世界和素材库合计 1,024 个不同在用模型、256 MiB 模型内容，以保证备份可搬移。详细格式见[导入说明](quality-import-and-navigation.md)和[组合与资产规范](groups-and-assets.md)。

个人素材库中若只保留了素材内容、世界里已无对应模型记录，服务端会核验内容并提供真实边界尺寸，再供预览和放置；缺失或损坏的内容会显示不可用，不能用猜测尺寸放置。Web 客户端的完整新流程需要重新导出并在浏览器单独验收。

## 权限与当前边界

只读账户可以探索和查看，不能建造。普通编辑者只可修改自己拥有的物体；地形与环境由区域所有者控制。当前门和灯的「使用」权限仍与所有权绑定，公开使用和独立编辑权限将在下一批处理。角色名称、共享标记、聊天、网络撤销、小地图、自动绕障及分块 LOD 仍未交付。此程序是 Godot 单区域客户端，不是 Firestorm 兼容 Viewer 或完整 OpenSimulator Grid。

网络界面的隔离验收入口是 `tools/Test-NetworkUI.ps1`。界面改变后必须查看实际截图；脚本成功退出只证明自动断言通过。
