此次场景构建得到 64 个资产、114,457 个三角形和约 6.93 MB 世界快照。独立网络客户端完成 64 块纹理加载、可行走出生点和实际截图；RegionStore 完成保存、约 4.11 MB 备份和新目录恢复。Godot 原生与可视化回归、网络 UI 隔离复测通过。并行运行大场景服务时，通用网络 UI 测试首次出现两项上传时序失败，停止该服务后的隔离复测为 71/71；需要固定负载与设备预算测试，才能确定并发容量。

2026-09-26 的增量验收覆盖世界模型工程链路 **20/20**（真实 Godot 权威服务、Agent、桌面审阅、重启与截图），动态账户资产访问 **13/13**，真实身份与重启回执 **43/43**；旧有原生 **212/212** 和可视化 **66/66** 回归亦通过。新增的预测输入仍是合成历史样本，世界模型 CLI 负责可审计的单点标记，不计算洪水范围或道路封闭；专家审阅文件保存在客户端，尚无服务器签名。

上述 64 块场景和 71/71 网络测试是本轮体验改造之前的基线。本轮已把导入网格容量提高到 96，JSON 快照改为版本 2 的内容引用，模型字节放在同名 `.assets` 目录；SQLite 使用内容目录及可搬移导出包。包含原 64 块在内的 74 个不同网格已通过 JSON 冷启动、备份恢复、SQLite 保存加载及导出恢复。共享客户端新增「探索 / 建造 / 我的素材」入口、可视放置与移动预览、旋转缩放、组合和个人素材复用。本轮原生测试 219/219、离线可视化 66/66、网络 UI 93/93、个人素材集成 40/40、存储 149/149 通过；详见[共享世界客户端指南](network-interface.md)。

赫尔辛基隔离实景的双客户端检查 6/6 通过：双方各载入 64 个带贴图网格并互相可见；一方放置物体得到持久回执后，另一方同步看到新增对象。[本轮实际界面总览](images/helsinki-current-workspace.png)已更新到根 README。近距离摄影测量仍有变形和模糊，不把这次容量与交互验收当成近景美术品质验收。
