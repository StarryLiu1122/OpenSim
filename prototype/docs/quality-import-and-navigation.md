# 清晰建筑资源、导入与漫游

航拍重建的实景三角网适合远距离看城市轮廓。近距离时，屋檐、树木、车辆和立面会产生不规则凸凹；提高相机精度不能修复源几何。要在街道上行走和建造，应优先选择**有明确墙面、屋顶和贴图的建筑模型**，把道路与地形作为独立层。

## 可用资源

| 资源 | 适合用途 | 导入路径 |
| --- | --- | --- |
| [赫尔辛基 3D 城市信息模型](https://www.hel.fi/en/decision-making/information-on-helsinki/maps-and-geospatial-data/helsinki-3d) | 官方 CC BY 4.0 LoD2 建筑；有纹理化版本，几何边缘比航拍网格规整 | 从官方下载服务取得带贴图的数据，按区域裁剪并导出 OBJ/MTL 或 GLB。单独的 Kalasatama CityGML ZIP 引用了未打包的 `appearance/*.jpg`，不能把那个 ZIP 当作完整贴图样例。 |
| [蒙特利尔 2016 LoD2 建筑](https://open.canada.ca/data/fr/dataset/5eabd047-872e-425a-bbc2-3669e732a132) | 部分行政区的带纹理 CityGML，可按图幅挑选真实街区 | 检查下载包是否含实际贴图，再转换成 OBJ/MTL 或 GLB。CityGML 本身尚不能在客户端直接打开。 |
| [Poly Haven 建筑模型](https://polyhaven.com/models) | CC0 的高质量立面、门窗和城市道具，可改善近景细节 | 下载 glTF，按下表控制单件大小；它们是制作资产，不代表某一真实地址的精确建筑。 |
| [3DBAG](https://3dbag.nl/) | 荷兰测绘建筑的规整体块和屋顶；当前代尔夫特样例使用此来源 | 现有 CityJSONFeature 转换脚本可生成 GLB，但来源不提供对应的真实立面照片。 |

## 当前格式与边界

| 输入 | 桌面客户端 | Web 客户端 | 条件 |
| --- | --- | --- | --- |
| GLB 2.0 | 直接选择 | 直接选择 | 静态、内嵌贴图、经过本项目的 GLB 子集校验 |
| glTF + BIN/PNG/JPEG | 直接选择 `.gltf` | 先在桌面或建模软件打包为 GLB | 外部文件必须与 glTF 在同一目录；不读取 URL 或上级目录 |
| OBJ + MTL + PNG/JPEG | 直接选择 `.obj` | 先转换为 GLB | MTL 和图片必须与 OBJ 在同一目录；支持三角面与四边面、多个不透明漫反射材质；导入时转为内嵌 GLB |
| CityGML、FBX、3DM、3D Tiles | 需先转换 | 需先转换 | 不会把扩展名伪装成已支持；CityGML 需处理坐标、瓦片和贴图依赖，FBX 可在 Blender 中导出 glTF |

单件当前上限为 **2 MiB、20,000 三角形、每轴 0.2–32 米、贴图不超过 1024×1024**；一个世界最多 16 个导入网格。大场景应先按地块分割并降面，不能直接把整座城市当作一个物体上传。OBJ 使用米制、Y 向上；导入器会对常见的 OBJ 面索引和同目录纹理做校验，材质和贴图最后保存在 GLB 里。需要 PBR 法线、粗糙度等贴图时，优先用 GLB/glTF，而非 OBJ/MTL。

桌面操作：在“场景”或“资产”页选择文件，填写真实许可和来源，点击“提交模型资产”，再选择模型放入场景。编辑器也可用 `ImportGlb` 命令输入本地路径。批量场景使用带 `source_crs`、`license`、`attribution`、SHA-256 和对象位置的 manifest；`build_city_pilot.gd` 接受 `region_size: 512`，并逐块通过 WorldService 校验和保存。

## 区域与控制

区域可在场景页由所有者扩至 **512×512 米**；原 256 米区域和存档继续可用。扩区保留旧的地形采样，并将边缘高度向外延伸，**不会自动获取新地形或建筑**。512 米仍是单区域原型，不是 OpenSim 的跨区域 Grid。

| 操作 | 控制 |
| --- | --- |
| 进入／退出漫游 | Tab；漫游时 Esc 返回编辑 |
| 漫游移动 | WASD、按住 Shift 快跑、空格跳跃、鼠标转向；按 F 切换飞行／落地 |
| 飞行 | WASD 水平移动，空格上升，Ctrl 下降；高度限制为 -5 至 80 米，水平位置限制在当前区域内 |
| 使用附近物体 | 对准 3.5 米内属于自己的门或灯，看到提示后按 E；切换结果以服务端保存回执为准 |
| 漫游镜头 | 滚轮或 Ctrl+0 / Ctrl+8 调整视角；Ctrl+9 恢复 |
| 编辑镜头 | 滚轮或 Ctrl+0 / Ctrl+8 拉近／拉远；Ctrl+9 或 Home 重置，右键拖动环视，中键拖动平移；Alt+左键对焦点击处 |
| 双击 | 地面双击前往；对象双击选择并定位 |
| 地点菜单 | 编辑状态下右键单击地面：前往、建造方块、放置当前模型、聚焦；右键单击对象还可选择或切换自己的门/灯 |

“前往此处”使用正常角色移动和服务端碰撞，不瞬移。路线是直线，撞到建筑后会停止并提示手动绕行；目前没有道路寻路。右键在近似垂直墙面上不会提供前往或建造。建造与放置仍由权威服务执行权限、边界和修订校验。

快跑和飞行采用客户端与权威服务共同支持的可选输入能力；连接旧服务时仍可普通步行。退出漫游会关闭飞行并恢复重力。靠近物体的 E 操作与右键切换都使用既有 `SetObjectState` 命令，因此只对所属对象开放，也不会绕开服务端权限。场景页的“在角色附近新建方块”使用角色前方地面，避免新物体反复出现在固定坐标。
