# V3 版本说明

版本：0.3.0。分支：codex/region-lab-v3。日期：2026-09-14。

## 1. 交付范围

V3 在已有地形和对象编辑能力上增加区域环境、更多对象类型与可持久化交互。首次创建图形世界时提供 43 个独立对象组成的展馆、庭院和湖岸；已有存档继续加载原场景。

| 模块 | 新增行为 |
| --- | --- |
| 场景 | 真实米制尺度的道路、建筑入口、室内陈设、树木与路灯 |
| 对象 | 方块、圆柱、球、伸缩门、树木、路灯；颜色和五类表面材质 |
| 环境 | 固定太阳时刻、日夜光照、天空、雾、水位与地形网格开关 |
| 交互 | 编辑模式开关门灯；漫游模式按 E 操作 4 米内目标 |
| 碰撞 | 门状态改变通行空间；球和圆柱使用凸碰撞，树干参与碰撞 |
| 存储 | 环境、材质与门灯状态统一保存；显式迁移 V1/V2 |
| 界面 | 环境页、资产选择、材质选择、漫游准星；漫游时隐藏两侧面板 |

## 2. 架构与接口

新增 BuiltinObjects、EnvironmentView、DemoRegion、EnvironmentPanel，分别处理内置对象投影、环境投影、示例数据与环境表单。世界记录与引擎节点继续分离。

新增命令 UpdateEnvironment 和 SetObjectState，UpdateObject 增加 material 字段。字段校验、归属、修订、失败返回及历史仍由统一命令服务处理。相同目标状态通过校验后视为无变化，不增加修订或历史。

命令封装版本仍为 1。世界格式升级到 2，CreateObject 须包含 material 和 state。内置目录扩展为六项；自动化样例已同步更新。

## 3. 数据兼容与启动

旧存档在读取时验证原结构，再在内存中补齐新字段。原 ID、坐标、地形和修订不变，原文件此时不改写。保存升级结果时保留原文件为有效备份。V1/V2 程序不能读取格式 2；备份会随后续保存继续轮换。

体验新场景应使用未存在的路径：

```powershell
cd prototype
.\Install.cmd
.\Start.cmd -WorldFile "$PWD\runtime\v3-demo.json"
```

首次保存之前示例只存在于内存。完整环境、安装与操作说明见 [使用说明](../../README.md)。

## 4. 验证

- 136 项原生数据、存储、迁移与物理检查。
- 50 项界面检查，包含 5 项真实渲染截图检查。
- 两个独立引擎进程验证环境、材质、门状态、物体和地形恢复。
- 三个离线批处理样例验证物体、地形以及环境与开门操作。
- 独立目录安装、首次启动和完整测试的结果见 [V3 固定提交的验证记录](https://github.com/StarryLiu1122/OpenSim/blob/3de81d513c8c2612604b33540df095e3e0644e2d/prototype/docs/verification.md)。

关键行为包括：关闭的门阻挡角色，开启后可通行；角色可进入示例建筑；旧格式迁移不在读取阶段改写文件。测试数量不代表所有参数组合或性能容量已验证。

## 5. 已知边界

这是程序化场景原型，尚非摄影级真实世界重建。水面没有浮力和水流，时间不自动推进，门没有连续动画。树冠用于显示，碰撞只覆盖树干。

建筑部件尚未组成 linkset。尚无外部资产导入、库存、完整脚本、数据库、多人同步或 Firestorm 协议。默认身份仍是本机测试身份，不能作为网络认证。

下一步为对象组合、受限制的真实资产导入与性能基线，再实施数据库和多人服务，见 [版本路线](../../../docs/plans/stage-one-rebuild-plan.md)。
