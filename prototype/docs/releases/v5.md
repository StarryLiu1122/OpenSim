# Region Lab V5 / 0.5.1

日期：2026-09-16。基线：V4.2 `07847e85f5850666c9a9d2083b80e81d1abaab92`。本次分支 `codex/region-lab-v5` 保留 V1～V4.2 历史。

## 实现内容

- 独立 Godot 权威区域，客户端只读投影；编辑经生产 WorldService 验证，世界与成功回执在 SQLite 同事务提交。
- FP 0.3 快照、增量、显式删除、世代、修订冲突、幂等结果查询和确认窗口；恢复缺失增量，约束慢客户端队列。
- 服务端角色输入、真实碰撞、自身预测与校正、远端插值；关闭客户端不会停止世界服务。
- 最小认证主体、显式共享授权、对象可见性和私有资产读取检查。
- 同协议桌面与 WebGL2 客户端，命令界面、门灯、GLB 文件选择、观察记录下载、指针锁、刷新及后台恢复。
- 距离兴趣范围、整组进入/离开、节点和资产缓存释放；必要碰撞资产经 HTTPS 字节数和 SHA256 验证后才开放操作。
- 固定单线程 Web 导出、中文字体许可及来源、启动脚本、完整离线包和 Windows / 双浏览器验收入口。

## 兼容和运行变化

世界格式仍为 3，领域命令版本仍为 1。SQLite 迁移到 schema 3；迁移前备份，旧程序不得打开唯一的已升级数据库。原版 OpenSim 网关继续使用 FP 0.2，不能直接当成现代网络端点。

原 `Start.cmd` 保留离线编辑器；网络模式按 [专用运行指南](../network-quickstart.md) 使用独立数据目录。网络增加 PowerShell 7 与 ASP.NET Core 8 运行依赖，默认 JSON 模式没有新增依赖。Web 画面采用顶点光照、无动态阴影和 MSAA 的轻量配置；桌面画面不变。

## 验收与限制

以 [V5 验收记录](../../../docs/comparisons/v5-completion.md) 的逐项状态、原始报告和性能门槛为准。当前验证针对 Windows 本机、小型单区域、两个实际客户端；不代表公网、低端硬件、长期运行或规模容量已验收。

完整 SSO、库存、智能体决策与外部平台任务闭环属于 V6；OAR 子集和更大真实场景属于 V7；容量和跨区域属于 V8。WebGPU、完整旧 Viewer 协议及脚本兼容仍是独立专题。
