# V3.1 版本说明

版本：0.3.1。分支：`codex/region-lab-v3-1`。日期：2026-09-15。

## 1. 新增能力

| 模块 | 行为 |
| --- | --- |
| 对象组合 | 根与子部件、局部变换、统一缩放；组合建立、整体变换、复制、解除和删除 |
| 编辑器 | Ctrl 多选、组合面板、资产导入面板；根部件位姿在组合页编辑 |
| 新建世界 | 展馆 15 个部件组成一组，门灯仍可分别交互；已有场景不自动重组 |
| 静态资产 | GLB 2.0 受限子集，支持 PBR 基础参数与内嵌 PNG 基础色；三类原始 CC0 样本 |
| 碰撞 | 可见网格或 COL_ 代理生成静态碰撞；建筑入口与内部空间保留 |
| 保存 | GLB 内容随快照保存；同一内容复用资产记录，多个实例独立编辑 |
| 验证 | 新增组合、导入、旧格式迁移、Jolt 通行、界面和独立进程恢复检查 |
| 性能 | 固定日景及 243 对象夜景测量，输出原始帧间隔、场景构建时间和资源监测 |

## 2. 数据和接口变化

世界格式升级为 3：新增 groups[]、对象必填 group_id、内嵌网格资产。读取格式 1/2 时先验证，再在内存中升级；显式保存才写入新格式。旧程序无法读取格式 3。

新增 GroupObjects、UpdateGroup、DuplicateGroup、UngroupObjects、DeleteGroup、ImportGlb、RemoveAsset，均经过原有 WorldService。命令封装仍为 1。GetRegionSnapshot 返回成员的局部存储字段，UpdateObject 接收世界坐标，详细规则见 [组合与资产规范](../groups-and-assets.md)。

旧有创建对象批处理样例已加入 group_id。外部调用方也需要补齐该字段；格式升级不会隐式修改调用方发送的新建命令。

## 3. 环境与使用

引擎保持 Godot 4.5.1 标准版、Jolt、Compatibility 渲染器。没有新增运行依赖；GLB 样本已提交，Python 仅用于可选的样本再生成。

安装和启动见 [使用说明](../../README.md)。体验组合展馆请使用新的世界路径。导入样本时在资产页填写许可 CC0-1.0、作者 Region Lab contributors，导入后从左侧添加实例。

## 4. 验证与限制

实测结果、实际截图和独立目录复现记录见 [验证记录](../verification.md)。固定工作负载及指标解释见 [性能基线](../performance.md)。

仍为本机单用户原型。组合是 OpenSim linkset 的受限语义映射；GLB 内部节点不转为独立脚本对象。模型仅支持静态、不透明、内嵌依赖的明确子集，未接入 OAR、CAD/BIM、摄影测量或在线模型服务。

每个资产上限 2 MiB、20,000 三角形，最多 16 个导入资产；快照上限 8 MiB。资源解析结果有缓存，显示 Mesh、材质和碰撞仍按实例构建，尚无 GPU 实例批处理或 LOD。性能记录不代表 500 对象容量、低端硬件帧率或生产环境可用性。

下一阶段从原版组合行为运行对照和存储契约开始，见 [V3.1 实施方案](../../../docs/plans/v3.1-implementation-plan.md)。
