# Region Lab V4.2 / 0.4.2

日期：2026-09-16。覆盖 V4.0、V4.1、V4.2。世界格式仍为 3，本地命令和快照封装仍为 1；已有 V3.1 JSON 存档继续可读取。

## 新增能力

- 固定 OpenSim 独立构建、两部件运行对照与 Firestorm 可视化核对。
- FP 0.2 原版网关：区域快照/事件、受控 Bot、动作回执、权限与持久结果。
- 可选 SQLite 仓储：原子提交、竞争写入拒绝、外置资产、迁移和备份恢复。
- 有原始测绘依据的 Pioneer Log Cabin GLB、碰撞代理与搬移恢复验证。
- Chromium/Firefox 的 WebGL2、物理、线程、文件导入、IDBFS 和隔离头实验。

## 从 V3.1 使用

更新 `codex/region-lab-v4` 分支后继续双击 `prototype/Start.cmd`。已安装的 Godot 4.5.1 可复用。默认仍保存 JSON，不会自动转换用户世界。

SQLite 需另外构建/安装 RegionStore 和 .NET 8；指定 `-Database` 与 `-StoreExecutable`。首次迁移前保留 JSON 副本，按 [存储指南](../../../services/README.md) 导入新目录。原版网关与桌面是独立路径，打开编辑器不需要 OpenSim 或 Bot。

## 验证与限制

最终桌面回归 188 项原生、66 项界面、2 类跨进程恢复、3 组批处理通过；新增 FP 42 项正常、30 项故障、282 项结构检查，SQLite 44 项、适配 12 项、公开启动 6 项通过。双浏览器、真实建筑和离线部署另有实测，完整口径见 [综合验收](../../../docs/comparisons/v4-completion.md)。

当前仍是本机单区域工程原型。现代多人权威服务、完整身份库存、正式 Web 客户端、在线模型、OAR 和规模验证未随 V4 交付。
