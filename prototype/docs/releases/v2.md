# Region Lab V2 版本说明

版本：0.2.0。基于 V1 提交 `89ecdfabbc919fc11ef059bc6dfcbaf8667c1a58`。

## 1. 新增功能

- 地形抬升、降低、设高和平滑笔刷，支持半径、强度、目标高程和中心坐标。
- 地表鼠标拾取与笔刷范围预览；一次点击对应一次编辑。
- 物体与地形共用撤销、重做历史，最多保留 30 次有效编辑。
- `SculptTerrain`、`Redo` 命令及离线地形操作样例。
- V1 存档读取、地形修改与再次保存的兼容性验证。

## 2. 行为调整

| 调整 | 原因与效果 |
| --- | --- |
| 地形显示与碰撞共享三角形 | 消除原高度场适配路径中的三角形划分及量化差异 |
| 地面查询使用分片线性插值 | 与可见三角形及碰撞面一致，并包含区域边界样本 |
| 地形更新保留物体节点 | 修改高程时不重建物体或改变其变换 |
| 角色避埋及出生点修正 | 地形抬升或读取存档时将角色放置在地面上方 |
| 无变化笔刷不增加修订 | 保留已保存标记和重做分支 |
| 修订上限原子校验 | 拒绝操作时保留世界数据及历史 |

## 3. 兼容性

Godot 依赖版本保持 4.5.1。世界格式、快照封装和命令协议版本均保持 1，V2 新命令属于操作集合扩展；V1 不支持新增操作。

已有 V1 存档可直接读取，地形与物体字段不需迁移。持久化内容仍不包含编辑相机、实时角色位置、撤销历史或请求缓存。兼容性样本来源见 [fixtures 说明](../../fixtures/README.md)。

升级方式：保存当前世界，关闭程序，切换 V2 分支后通过同一 `-WorldFile` 启动。引擎版本未变化，已校验的 V1 引擎安装可以复用。

## 4. 测试与文档

V2 包含 86 项原生检查、32 项界面与渲染检查，以及独立进程恢复、物体批处理和地形批处理。具体执行结果以 [验证记录](../verification.md) 为准。

文档按项目概述、使用说明、接口规范、数据对应、技术决策、版本说明和开发计划组织。历史 C# 方案作为维护参考保留，当前功能范围以本版本文档为准。

## 5. 已知限制

- 本机单用户、固定区域；尚无数据库服务、多人同步和完整身份认证。
- 地形按 4 米间距采样，使用单次笔刷；不支持连续拖动、地形洞穴和地表纹理绘制。
- 笔刷修改后整体重建静态地形网格及碰撞，尚未完成容量或延迟基准测试。
- 物体不随地形自动移动；地面放置仅为中心点的直立方块放置。
- 尚未支持库存、LSL/OSSL、外部网格导入、Firestorm 或在线模型。
- 固定 OpenSim 源码的构建与运行对照仍待完成。

后续优先级为原版行为基线、数据库持久化、双客户端同步，详见 [开发计划](../../../docs/plans/stage-one-rebuild-plan.md)。
