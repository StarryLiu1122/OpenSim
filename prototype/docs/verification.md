## 2. 执行方法与结果

在 `prototype` 目录执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\Test-RegionLab.ps1 -Visual
```

| 检查组 | 结果 | 覆盖内容 |
| --- | --- | --- |
| 原生数据、存储和物理 | 86 / 86 通过 | V1 回归、笔刷、历史、边界、旧存档兼容、真实碰撞与角色行为 |
| 界面与渲染 | 32 / 32 通过 | 物体与地形编辑、鼠标拾取、保存恢复、撤销重做、角色避埋及截图 |
| 独立进程恢复 | 通过 | 一个引擎进程写入并退出，另一个进程恢复物体及编辑后的高程 |
| 物体批处理 | 通过 | 创建、保存、查询，对象数由 8 增至 9 |
| 地形批处理 | 通过 | 设高、撤销、重做、保存与查询；目标采样高程为 8 米 |

报告：[汇总](evidence/summary.json)、[原生检查](evidence/native-report.json)、[界面检查](evidence/visual-report.json)。完整运行日志位于本机 `test-results/run-.../`。

界面测试通过 Godot Viewport 注入点击和按键事件，属性字段通过控件接口赋值。32 项中包含 3 项截图生成检查。截图已审阅中文显示、面板范围、笔刷轮廓和场景内容；测试数量不等于完整功能覆盖率。

## 3. 重点用例

| 类别 | 检查内容 |
| --- | --- |
| 笔刷算法 | 中心增量、径向衰减、范围外不变、设高目标、3×3 平滑及遍历顺序独立性 |
| 输入与权限 | 参数范围、未知字段、非有限数值、区域归属和重复请求 |
| 历史 | 一次笔刷整体撤销、重做、新编辑清除重做、无变化操作保留状态、30 步上限 |
| 修订 | 旧修订拒绝；修订上限处编辑与历史操作保持原子性 |
| 存档 | 高程及物体恢复、损坏备份、失败写入、外部文件修改检测 |
| 兼容 | 读取 V1 实际存档，保留原物体标识和属性，继续编辑并保存 |
| 几何与物理 | 网格顶点、非共面格网内部四点、地形更新、撤销后碰撞、角色落地 |
| 界面状态 | 鼠标位置写入笔刷中心、应用后数据与碰撞更新、加载清除历史 |
| 角色位置 | 地形抬升时避免角色埋入，存档起点高程变化后正确放置角色 |

数值标准：快照浮点数据恢复容差 `1e-6`；指定射线与网格高度检查容差 0.002 米；角色落地采用适合胶囊接触的 0.2 米容差。上述值为测试判据，未声明为全场景误差上界。

## 4. 独立目录复现

从 Git 暂存内容导出原型至同一机器的全新目录，目录名包含空格，不包含项目缓存、引擎安装或用户存档。使用固定官方压缩包离线安装，再执行首次启动和完整测试：

```powershell
.\Install.cmd -ArchivePath "<已校验的官方压缩包绝对路径>"
.\Start.cmd -WorldFile "$PWD\runtime\launch.json" -Screenshot "$PWD\test-results\launch.png"
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\Test-RegionLab.ps1 -Visual
```

首次启动在编辑器导入和测试之前进行。源码文件与实际测试副本逐字节比较，记录见 [独立目录报告](evidence/clean-reproduction.json)。该验证适用于同一台 Windows 机器的新目录，不覆盖全新操作系统或其它平台。
