## 2. 关键缺陷与修复

| 验收中发现的问题 | 最终处理与复测 |
| --- | --- |
| OpenMetaverse 使用 .NET 8 不支持的 Thread.Abort | 固定源码，以唤醒/停止/Join 协作退出；正常及强制中断实验无该异常 |
| 客户端补丁在嵌套仓库中被 Git 跳过 | 导出源树建立独立 Git 上下文，检查补丁后置条件；记录实际产物摘要 |
| 崩溃后原版保留账户在线标记 | 仅对特定 presence 拒绝重试一次，不放宽重复登录策略；显式重连和退出通过 |
| 遥测导出递归包含以前的导出回执 | 排除 TelemetryExport 回执；重复导出和响应边界检查通过 |
| JSON 校验往返改变浮点末位 | 格式 3 校验后保留原数值文本，旧格式使用迁移结果；完整世界深比较通过 |
| Web 独立目录中相对模板路径失效 | 入口解析绝对路径，重新导出并完成双浏览器矩阵 |
| 桌面参数被 PowerShell 拼为一个字符串 | 参数分别加括号；新增公开启动验收，核对数据库路径、44 对象、资产、修订及已保存状态 |
| Viewer 捕获失败、退出截图为黑帧 | 恢复可用桌面后重新观察窗口，保存根/子部件编辑截图；黑帧未计入证据 |

## 3. 下一阶段

V4 完成的是本机工程验证链：原版与模拟平台完成 FP 闭环，现代原型完成可选事务仓储，Web 与真实建筑输入取得实测依据。默认 JSON 使用方式和世界格式保持兼容。

后续按 [V5～V8 路线](stage-one-rebuild-plan.md) 推进。V5.0 首先建立现代区域权威服务，将已验证的 WorldService、仓储、主体及 FP 世代/序列合同移到服务端；再验证双客户端竞争、断线恢复和收敛，接入正式 Web 轻客户端。真实平台认证/端点、科研任务和城市资产仍需项目输入。

未交付 DLL 热替换、任意脚本/库存兼容、导航寻路、长期稳定性、硬件断电恢复、跨平台或容量保证。模块重启证据采用进程冷重启，具体边界见验收报告。
