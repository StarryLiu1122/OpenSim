## 3. 本轮发现及处理

| 发现 | 处理与后续影响 |
| --- | --- |
| 原版组 UUID 与根 UUID 相同；现代组 UUID 独立 | 保留语义差异，后续映射表区分组与成员，不直接复用主键 |
| 原版统一缩放改写偏移和尺寸；现代组保存倍率 | 以合成世界位姿对照，不逐字段判等 |
| 原版复制需要在线操作者 | 使用真实 Bot 后走原权限检查；离线明确返回 OPERATOR_OFFLINE |
| OpenMetaverse 退出回调使用 Thread.Abort | 记录兼容性缺陷，未屏蔽；原版确认 Avatar 离场，Bot 进程退出；完整 V4.1 验收前需修复 |
| 客户端运动回报不能证明到达任意目标 | 首轮限定两秒前进的有界运动，由区域观察确认；MOVE_TO 保持未实现 |
| 原版和原型的校验范围不同 | 当前适配器只限中心坐标和静态尺寸；完整旋转占地、地块和多主体规则独立补齐 |
| 当前接口计数不覆盖 Viewer/物理变化 | 明确 adapter_sequence 的范围，不当作世界修订或事件流序号 |
