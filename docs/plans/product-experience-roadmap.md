# Region Lab：以探索和建造为中心的实施路线

更新日期：2026-09-26。本文用于把现有单区域原型推进为可长期使用的共享街区。当前阶段优先改善真实场景、界面、编辑和协作体验；新的智能体或世界模型接入暂不作为前置条件。

## 用户任务与验收方式

以一条完整任务代替零散功能演示：用户进入街区，找到一个地点，导入或选用素材，在场景中预览并放置，调整物体，退出后重新进入，第二位用户能看到已保存结果。每一步应有明确入口、状态和失败反馈。测试必须使用新建的隔离世界，不能覆盖现有演示实例。

## 第一批：打通基础创作流程

| 工作 | 可观察验收 |
| --- | --- |
| 把 JSON 快照中的模型二进制改为按 SHA-256 引用的独立内容目录 | 旧存档可迁移；快照、资源目录一起复制后可恢复；缺失或损坏资源被拒绝；现有 64 模型场景还能继续加入素材 |
| 重新组织网络客户端 | 探索、建造、我的素材是常用入口；连接和诊断容易找到但不妨碍进入场景；地形与环境等常用操作无需手填 JSON |
| 可视建造 | 场景内可预览位置并取消；可修改位置、朝向与尺寸，明确显示待保存和服务端回执；两端结果一致 |
| 持久素材库 | 重新登录后仍能找到未放入场景的自有素材，并能从库存放置；对象可复用同一资源而不复制二进制 |

第一批完成条件：桌面端在一个隔离的真实场景中走通完整用户任务；旧存档、数据库和网络 UI 回归通过，并检查实际渲染截图。Web 端仍需独立导出和浏览器复验，不能以桌面结果替代。

## 第二批：街区可探索、可协作

1. 为街道建立地点、返回点和小地图。改进“前往此处”的绕障与失败提示，并补齐可配置键位。
2. 把“使用门灯”与“编辑物体”拆分成不同权限，使访客能参加公开互动；增加地点标记、角色名称和基础交流。
3. 完成网络多选、组合、复制、吸附与共享撤销，保留修订冲突和服务端授权语义。
4. 在真实地理背景上制作一段质量可控的街面路线，把后期制作的建筑、道路和道具与测绘内容明确区分。

## 第三批：发布与容量

加入场景版本和恢复入口、素材搜索与预制件、可复现导入报告；再基于固定设备和网络条件测量首屏、帧率、内存及多人负载。按结果增加资产缓存、分块加载和 LOD。当前数据库已有内容寻址资源目录，但服务进程仍会装载完整世界，不能仅凭快照瘦身宣称城市级容量。

每批更新用户操作文档和验收证据；未通过的项目保留为待办，不以计划文本代替交付。
