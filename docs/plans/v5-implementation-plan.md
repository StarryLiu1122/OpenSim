# V5 权威区域与桌面 / Web 客户端实施计划

日期：2026-09-16。状态：V5.0 已完成，V5.1 功能已实现，5.1-06 冷启动预算未通过；基线 V4.2 `07847e85f5850666c9a9d2083b80e81d1abaab92`，开发分支 `codex/region-lab-v5`。覆盖总体路线的 5.0-01～06、5.1-01～06 共 12 项任务。原版 FP 0.2 保留；现代传输使用独立版本，不改变世界格式 3。

## 1. 实现顺序

1. 固定现代 FP 合同、会话、区域事务与回执原子性；建立独立 Godot headless 权威进程。
2. 实现两个桌面客户端的只读投影、命令、真实角色碰撞、确认与校正。
3. 验证冲突、重复、乱序、断线、服务重启和数据库失败，保存跨进程记录。
4. 接入 WebGL2 / WebSocket，建立距离过滤、可靠进入/离开与按需资产读取。
5. 在 Chromium 和 Firefox 验证刷新、后台、缓存、重连、文件入口和首包；更新部署、迁移及回滚说明。

## 2. 结构决策

- 权威服务继续调用生产 WorldService 和 Jolt；网络线程不能绕过领域校验或接受完整世界覆盖。
- SQLite 在单事务中发布世界及网络命令的成功回执。确认前不把候选发布给客户端；存储工作异步执行，角色步进保持运行。
- 客户端只读 LocalWorldView 接收快照和增量；编辑不作本地确认。移动采用本地预测、远端插值及服务端校正，输入不包含可信位置。
- ASP.NET Core 8 仅承担 Web 文件、HTTPS 资产和 WebSocket 转发；世界权威仍只有 Godot 进程。使用现有 .NET 8 运行时和固定依赖，不增加数据库服务。
- 会话为新实例生成的本机测试主体，令牌不嵌入 Web 构建或 URL。真实 SSO、库存与智能体策略属于 V6。
- 浏览器采用已验证的单线程 Jolt / WebGL2。静态资源压缩和独立缓存策略纳入实际首包测试。
