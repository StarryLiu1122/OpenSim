### 浏览器后台用例的测试范围

Playwright 对页面焦点和可见性进行模拟；本机即使窗口最小化，`document.hidden` 仍可能为 false。因此测试核对本次浏览器进程树的原生窗口 `IsIconic`，并显式暂停页面的帧 / 定时器时钟。暂停期间原有观察序列保持不变，另一个桌面提交成功；恢复时钟、还原窗口并请求快照后收敛。报告保存真实 `document.hidden` 值，未把模拟值写成实际隐藏事件。

这个用例验证前端停止推进时权威服务仍独立运行；它不等价于所有零售浏览器的标签页节流、操作系统睡眠或移动端后台行为。产品保留 `visibilitychange` 的恢复处理，普通浏览器的长期后台和系统休眠仍需后续专项验收。

## 3. Web 冷启动与性能结论

测量从导航开始，到认证、必要资产校验、真实碰撞投影及首个已渲染可操作状态结束，包含自动输入令牌的耗时。入口为本机 HTTPS，静态文件和资产共享 **50 Mbps** 响应体发送节流；没有模拟 WAN RTT、抖动、丢包或互联网 TLS 部署。每次冷启动使用新浏览器进程和临时配置，未清操作系统文件缓存或驱动缓存。热启动结果不能替代冷启动。

固定场景为 44 对象、15 部件展馆组、一栋真实测绘来源的静态 GLB 建筑；功能测试新增的长凳在下一次测量前删除。两个浏览器上下文均配置 1440×960 CSS 视口和 deviceScaleFactor=1；系统显示缩放仍可能影响截图输出像素，截图文件尺寸不作为首包指标。Web 固定顶点光照、Lambert、无动态阴影和 MSAA；桌面保留原配置。引擎归档、单线程模板及导出文件都有摘要记录。

硬件：Windows 11 10.0.26200、Core Ultra 7 255HX、约 16 GB 内存、平衡电源计划。桌面使用 RTX 5060 Laptop GPU；浏览器报告 Intel 图形 / ANGLE D3D11。具体驱动和完整资源计时见 [硬件记录](evidence/v5-20260916/hardware.json) 与 [Web 报告](evidence/v5-20260916/web-report.json)。

| 浏览器 | 五次冷启动 / 秒 | 中位数 / 秒 | 最大值 / 秒 | 热启动 / 秒 | ≤10 秒 |
| --- | --- | --- | --- | --- | --- |
| chromium 151.0.7922.34 | 8.869, 7.615, 7.641, 7.639, 7.624 | 7.639 | 8.869 | 3.619 | 5/5 |
| firefox 153.0 | 10.678, 10.377, 10.395, 10.236, 10.282 | 10.377 | 10.678 | 8.558 | 0/5 |

Firefox 仍超过规划规定的 10 秒门槛，5.1-06 保留未通过。之前的定位与优化包括压缩传输、按类别缓存投影摘要、避免碰撞体构建时从 GPU 回读、限制未确认更新、统一像素比例和固定轻量光照。继续工作应集中于 Firefox 的首帧与 WebAssembly / WebGL 启动分析，使用同一场景和完整冷样本复验；不能通过排除失败样本、提高带宽或缩小验收范围宣布达标。

## 4. 部署、迁移与自动化

运行入口见 [V5 网络指南](../../prototype/docs/network-quickstart.md)。首次启动会导入工程资源，服务与客户端使用独立实例目录。正式两个客户端启动命令均为非阻塞，可在同一终端连续执行。数据库 schema 3 使用事务迁移；备份包含世界和资产，认证配置与历史网络回执不装入导出包。回滚应使用升级前备份。

在同机新建的含空格目录中，使用固定 Godot 归档、已验证的 RegionStore / RegionHost 和 Web 导出构建离线包，安装器完成 **428 个文件的 SHA256 校验**。包不带 `.godot` 缓存；正式服务入口完成首次资源导入，两个客户端命令先后返回且均建立真实桌面窗口。独立观察会话看到两个编辑主体及自己共 3 个 Avatar、44 个对象、1 组。关闭两个客户端后服务继续响应；停止后实际权威 PID 及网关端口均退出；从同一目录重启后修订 2 和 44 个对象恢复，网络世代更新。11 项部署检查通过，见 [部署报告](evidence/v5-20260916/deployment-report.json) 与 [包文件清单](evidence/v5-20260916/package-manifest.json)。

此包是本轮隔离验证产物，没有随源码提交运行二进制。清单记录打包当时的文档和证据快照；随后仅补充文档、证据和测试计时字段，运行代码及启动脚本已与验收输入核对。目标机预装 PowerShell 7 和 .NET / ASP.NET Core 8，安装与启动没有访问网络或重新构建；该结果不等同于全新操作系统安装测试。

本地完整自动化入口为 [Test-V5.ps1](../../prototype/tools/Test-V5.ps1)。[GitHub 工作流](../../.github/workflows/region-lab-v5.yml) 使用手动触发及标签为 `region-lab-gpu` 的 Windows 自托管执行机，要求交互桌面、固定 Godot / Web 模板、SDK 8.0.424、Node 24、Playwright 1.62.1 和 Python。当前未在 GitHub 执行该工作流，不能声称远程 CI 已通过；冷启动超预算会使相同测试入口失败。
