## 发布与复现

浏览器最终复测使用 Chromium 151.0.7922.34、Firefox 153.0，各启动五个独立新进程和临时配置。50 Mbps 网关响应限速下，Chromium 冷启动 5.305–5.661 秒，中位数 5.326 秒；Firefox 6.993–7.208 秒，中位数 7.063 秒。十个最终样本均达到原有 10 秒门槛。测量为本机回环连接，未清空操作系统和驱动缓存，不代表公网、低端硬件或容量保证，也不改变历史报告中的原始结果。

保留两次前序失败记录：

1. [鼠标捕获初次报告](web-pointer-initial-report.json)：Firefox 异步获取指针锁时，客户端过早退出漫游。修正为等待浏览器实际取得指针锁，再监测释放，并保留获取失败提示。
2. [冷启动初次报告](web-startup-initial-report.json)：前述修正后的第三次 Firefox 冷启动未处理登录操作，等待超时。测试入口增加显式页面激活，并保留失败运行的控制台日志；新实例完整复测通过。该次超时的底层原因未被完全定位，不能仅凭一次复测宣布所有环境均已消除启动波动。

两个浏览器的实际画面：[Chromium](chromium-cold.png)、[Firefox](firefox-cold.png)。高 DPI 时按浏览器 CSS 尺寸布局，保持字体与按钮可读。正常手势进入漫游、Esc 释放鼠标、浏览器与桌面互改、资产损坏阻断、重试恢复、会话清理及回执行为均通过。
