# V4 存储合同草案

日期：2026-09-16。状态：**设计输入，仓储与数据库尚未实现，尚未完成 4.0-07 及 V4.2 验收**。本次原版运行使用 OpenSim 自带 SQLite，仅作为行为对照，不能计为现代原型的数据库交付。

## 1. 数据与权威边界

Region Lab 世界格式继续为 3。区域、对象组、部件、资产元数据、资产二进制与未来库存条目分别建模。Godot 节点、HTTP 会话、Bot 客户端对象和物理句柄不持久化为世界记录。

原版对象组身份由根部件 UUID 表达；现代组使用独立 UUID。未来映射表至少记录 `source_runtime/source_region/source_entity_id/modern_entity_id/entity_kind`。不能令现代组和根部件共享主键，也不能通过名称重新关联。原版 Child OffsetPosition 的缩放结果必须先投影，不能直接覆盖现代局部变换加组倍率。

## 2. 仓储执行合同

| 操作 | 输入 | 成功语义 | 必须拒绝 |
| --- | --- | --- | --- |
| LoadWorld | region_id | 读取同一提交点的世界与全部必要内容 | 不支持 schema、缺失资产、摘要损坏、悬空成员 |
| CommitWorld | region_id、expected_revision、完整候选世界、request_id | 在一个区域事务中检查期望修订并提交组/成员/引用/新修订 | 修订冲突、候选无效、部分组合、跨归属关联 |
| PutContent | 原始字节、完整 SHA256、受控元数据 | 暂存校验后发布不可变内容；相同摘要复用 | 摘要不一致、超限、未知或不允许格式 |
| ExportWorld | region_id、受控输出位置 | 一致提交点的清单、世界、全部必要资产与摘要 | 缺失内容、导出过程中混用两个修订 |
| ImportWorld | 经路径与大小检查的导出包 | 在空目标或显式恢复目标中完整验证后提交 | 路径逃逸、重复项、超限、不支持版本、坏摘要 |

执行区域修改的校验仍应复用 WorldService/WorldSchema，数据库后端不能自行绕过业务约束。如果选择 C# 服务，应保留 Godot headless 校验入口，或以共享合法/非法样例验证等价规则；具体方案写入 V4.2 ADR。

## 3. 事务与故障语义

1. 先校验候选世界，再校验并发布必要二进制；仅在二进制可读且摘要正确后进入引用提交。
2. 在同一个数据库事务内比较 expected_revision、修改所有实体及引用、更新修订。不得先读修订，再无条件写库。
3. 文件发布成功、数据库失败时可能留下孤儿内容；保留隔离期并按提交引用回收，不能删除可能被并发导入引用的内容。
4. 数据库提交完成后回应丢失时，调用者通过 request_id 查询提交结果。没有持久回执之前，不能声明跨进程“恰好一次”。
5. 任一必要内容损坏时正式恢复整次拒绝；保留已有有效世界，不能静默删除物体。
6. 历史快照恢复产生新的运行世代；世界 revision、数据库迁移号、存储封装版本和实时流序号分开管理。

初期以单区域完整候选作为事务边界，保留现有 JSON 快照路径。区域事务没有自动覆盖文件系统的能力；未来对象存储也遵守先发布内容、再提交引用的顺序。

## 4. 迁移、导出与备份

世界格式 1/2/3 由现有迁移与校验入口解析，读取旧格式不自动覆盖源文件。外置二进制优先升级存储封装；只有业务语义变化才升级世界格式。

导出包应具有固定封装版本、工具版本、世界清单、资产相对路径、完整摘要、许可及来源元数据。解包限制总字节、文件数、单文件大小、目录深度，拒绝绝对路径、上级路径与重复项，不执行包内脚本。

备份必须声明一致性点、保留策略、恢复命令和数据损失范围。写入中断、发布内容后数据库失败、损坏备份、全新目录恢复与旧版本回退分别设置独立用例；进程终止测试不替代断电测试。

## 5. 尚待选型与验证

| 决策 | 候选与需验证内容 | 落定时点 |
| --- | --- | --- |
| 数据库 | SQLite 适合单机原型；PostgreSQL 适合独立服务和并发运维；需比较 CAS、迁移、备份和部署成本 | 4.2-01 ADR |
| 仓储语言/位置 | Godot headless、复用 C# 工具链或其他独立服务；以规则复用和部署条件选择 | 4.2-01 ADR |
| 二进制仓储 | 本机哈希目录起步；对象存储通过相同内容合同接入 | 4.2-05 |
| 导出容器 | 包格式、字节上限、版本与重复项策略须由恢复实现和攻击样例确定 | 4.2-06 |
| 真实建筑元数据 | 授权来源、尺寸、碰撞净空和转换清单，不能用现有示意展馆替代 | 4.0-05 后回填 |

该草案明确下一阶段需满足的存储语义，当前没有通过事务、迁移或导出实现证明这些承诺。
